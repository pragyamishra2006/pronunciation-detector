# 🎤 Pronunciation Detector

Real-time speech analysis tool that detects pronunciation errors and provides instant feedback to improve spoken English skills.

## ✨ Features
- 🔊 Record and analyze speech instantly
- ✅ Real-time pronunciation accuracy scoring
- 🎯 Phonetic breakdown with error highlighting
- 🔄 Multiple language support
- 📱 Simple, intuitive web interface

## 🚀 Quick Demo
1. Type or paste any text/sentence
2. Click "Listen to correct pronunciation"
3. Record your pronunciation
4. Get instant feedback with accuracy score!
